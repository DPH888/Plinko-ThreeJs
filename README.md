# Plinko - Three.js & Cannon-es Physics Game

A interactive **Plinko** simulation built with **Three.js** and **Cannon-es** physics engine. This is a school project demonstrating 3D graphics and real-time physics simulation.

## Technologies Used

- **[Three.js](https://threejs.org/)** - 3D graphics library
- **[Cannon-es](https://pmndrs.github.io/cannon-es/)** - Modern JavaScript physics engine
- **[Node.js](https://nodejs.org/)** & **[npm](https://www.npmjs.com/)** - Development environment
- **[Webpack](https://webpack.js.org/)** - Module bundler

## Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)
